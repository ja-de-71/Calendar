Import Bookings (CSV)

Upload a CSV file to create multiple bookings at once.

Format: name,phone,email,date,startTime,endTime,rinks,notes

Example: John Smith,0212345678,john@email.com,2025-12-01,09:00,11:00,"1,2,3",Tournament

Important:

  • Date must be YYYY-MM-DD (e.g., 2025-12-01)
  • Times must be HH:MM with leading zeros (e.g., 08:00, not 8:00)
  • Put rinks in quotes if multiple: "1,2,3" not 1,2,3
